# Portfolio Project: Data Cleaning in SQL

## Overview
This project focuses on data cleaning and transformation using SQL in DBeaver. 

## Acknowledgments & Attribution
* **Guided Tutorial:** This project was completed by following the SQL project tutorial series by **Alex the Analyst** on YouTube.
* **Original Project Reference:** [Alex The Analyst YouTube Channel](https://www.youtube.com/@AlexTheAnalyst)
* **Dataset:** Original dataset provided as part of the Alex the Analyst SQL Bootcamp series.

## Project Structure
* `scripts/`: Contains `.sql` files for data cleaning and exploration.
* `data/`: Raw and cleaned CSV files exported from DBeaver.
